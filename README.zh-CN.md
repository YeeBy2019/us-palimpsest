# us-palimpsest

[English](./README.md) | **简体中文**

> 一张可以走进的美国历史地图。手绘雕版，粒子消散，时间作为第一公民。

**us-palimpsest** 是一个基于 Three.js 的交互式美国历史三维地图集。它把不断变化的疆域、城市的兴衰与决定性的历史事件，绘制在同一张可探索的手绘地图上。时间是第一主轴：时间轴按分节推进，边界如墨水洇开般生长，城市光点逐次亮起；一个时代向另一个时代过渡时，粒子消散开来，又落回纸面。

它同时也是**写出来的**：八章共承载一百零八个带日期的时刻——一条路、一次行军、一场投降、一篇演说——游标会停在上面，把它读出来。在国土轮廓已经不再移动的地方，这些故事不是地图上的点缀，它**就是**版面据以绘制的东西。

美术方向参考 [Chartogne-Taillet](https://chartogne-taillet.com/en)——由 Immersive Garden 制作、Bruno Simon 开发，2020 年 12 月 2 日获 Awwwards 每日最佳网站。我们从它身上取几样东西：雕版地图的观感、可见纸面上的水彩晕染、克制的用色，以及唯一一种转场装置——动画粒子——由它把物质从一个场景带到下一个。

## 美术原则

五条，取自参考案例，视为硬性约束。

**1. 一章一种材质。** 每章都渲染成一种可信的实体物质：雕版线条、墨水渲染、水彩洇染、蓝图网格、新闻纸、雷达荧光。章内不混用材质。

**2. 克制的用色，留三处刻意破例。** 参考案例整站建立在单一颜色（`#987654`）之上。我们在全图保持"纸与墨"的基调，各章靠*技法*区分——网线密度、线宽、晕染软硬、洇散半径——而不靠色相。只有三个时刻配得上硬性换色：分裂章的暗红、二战的雷达绿、千禧年的屏幕白。因为稀有，所以有效。

**3. 粒子是唯一的转场。** 只用一种装置，贯彻到底。参考案例从不硬切、从不交叉淡入；上一幕被消散成粒子，而这些粒子成为下一幕的材质。我们照做，并且不再引入第二套转场语汇。

**4. 时间是分节的，不是全局滑动的。** 见下文「时间轴模型」。

**5. 层是沉积下去的，不是叠加上去的。** 见下文「重写本原则」。

## 重写本原则

**结论：层叠要做——但做成纸面之下的沉积，而不是盖在纸上的半透明叠加。**

理由来自参考案例。Chartogne-Taillet 之所以可信，是因为画面里的一切都属于同一种物质：雕版线、水彩、深褐。它的转场并不保留上一幕——笔刷*变成*气泡，气泡*变成*下一幅插图。在新场景之上叠一层半透明的鬼影多边形，会破坏这种统一。在雕版印张上，一道淡淡的错位轮廓读起来像套印误差，而不像历史。

所以这是一条有边界的"要"：

- **只留锚点，不留每一层。** 每章最多保留一到三个*锚点*——历史上具有决定意义的边界状态（1783 年条约线、1803 年购地、1848 年割让、1861 年脱离线）。不是每一代都留，也绝不一次性铺满整部历史。
- **锚点用当章自己的材质来画。** 被保留的边界是去饱和的雕版网线，绝不是一块半透明填色。
- **转场一箭双雕。** 让旧边界消散的那些粒子，正是随后沉积为网线的同一批粒子。消散与沉积是同一个动作，不是两个。
- **锚点在之后两章内可辨，再往后就只是纸。** 拥有它的那一章以全强度绘制；其后两章以递减的网线密度绘制；从第三章起它只是纸纹——不再参与几何绘制，也没有填充率开销。
- **这个窗口本身就是可见上限，不是第二条规则。** 因为窗口是两章，纸面上任何时刻都不会超过三个锚点。「至多可见两到三个」是上一条的算术结果。
- **窗口按章计，不按年计。** 章是导航单位，且各自带有时间尺度。按年计会自相矛盾——1783 年的锚点在第 2、3 两章里会横跨 82 年，而第 6 章里的锚点四年就没了。重写本描述的其实是*页距*：那笔墨是几页之前看到的。

这就是项目名的意思：纸被反复使用，早先的墨迹仍隐约可辨。

## 叙事层

这个项目里其他每一层都是几何。章节的年份区间切出边界，时间轴是在这些边界上的 scrub，锚点是被保留的边界状态，插图框也是边界几何，连章节卡片讲的都是版面所印的*材质*。合起来，这张地图只认得一种事实：**某个地方的轮廓在某一天变了**——而它不足以讲出项目名字所承诺的那段历史。

对第 2–5 章够用，因为那些章节的轮廓确实在动；对第 1 章不够用——它的窗口里一条州界都没有——对第 6、7、8 章也不够用，因为轮廓已经停了：1912 到 1959 年间没有任何州加入，这几章整个窗口画的是同一条海岸线。**一张只在边界移动时才会说话的地图，对第二次世界大战无话可说。**

于是有了第二种内容类型，而它不只是"同一种东西再多一点"，而是一种不同的东西。边界是**推导**出来的：切它、投影它、画它，全程没有掺进任何人的判断。故事是**撰写**出来的：得有人决定珍珠港是一个节点、柳溪轰炸机厂是另一个节点，还得有人把句子写出来。AHCB 里没有「广岛」这个词。

一个**叙事节点（beat）**是一个时刻：一个日期、地球上的一处地点、以及发生过的一件事。

```js
{ id: 'd-day', date: '1944-06-06', kind: 'battle',
  place: { lon: -0.87, lat: 49.36, name: 'Normandy, France', nameZh: '法国诺曼底' },
  title: 'D-Day', titleZh: '诺曼底登陆', body: '…', bodyZh: '…' }
```

数据在 `src/timeline/narration.js`。**截至 2026-10-10 八章全部写完，共一百零八个节点**，从詹姆斯敦建立到国会山遇袭。那里的"没有条目"意味着**还没写**，不是"构建失败"——即便现在一条都不缺，文件依然保留这个区分。每条字符串都同时带中英两份，沿用 `chapters.js` 里 `name` / `nameZh` 的形状；两个版本是同一个叙述，而不是互为译文。

这些文字依据公开史料自行写出，不引用任何来源。纪录片只作章节骨架（`chapters.js` 的 `episodes` 字段），它的画面、音频与解说词一律不进仓库；见「许可」。

### 唯一一处由手绘出的线

故事要展示的东西里，有些是这份记录画不出来的：一条路、一次行军、一条测绘线、一条由国会法案而非由测量员命名的纬线。因此一个节点可以携带 **`figures`**——一条或多条真实经纬度的折线，在游标越过该节点日期时显影于版面，和边界完全一样。

共十四处，分属四个章节的十二个节点。溯詹姆斯河而上到詹姆斯敦；大篷车道与 1763 年宣告线的山脊线；通往大草甸的尼马科林小径；出波士顿到康科德的那条路；约克镇联军行军；刘易斯与克拉克；密苏里妥协案命名的纬线；伊利运河；1846 年条约命名的北纬 49 度线与俄勒冈小径；驿马快信；谢尔曼向大海进军；第一条横贯大陆铁路。

三条规则，正是它们挡住了"什么都能往里塞"：

- **它是走廊，不是测量。** 这块版面上其他一切都是推导出来的、精确的。而 figure 是依据公开描述描出来的，并且坦率承认自己是近似的——所以每条都带一个 `note`，是示意的时候就写 *schematic*。
- **它属于某个节点。** figure 没有自己的日期，节点显影它就显影。一句话都不需要的那条线叫装饰。
- **管线只读这一个字段。** `pipeline/build.js` 把 `figures` 投影进章节包，从不看 `title` 或 `body`；所以没人写过的章节照样能构建，和写过的别无二致。叙事层不会变成地图的构建依赖。

**没有它们，第 1 章根本上不了版面。** 触及它窗口的每一个要素都起始于它的结束日，因此这一章的包唯一能画的就是它自己的路线。也正是在这里，地图集从"一张地图外加一段注解"变成了"一段注解外加一张地图"。

而一个依赖 figure 的章节，依赖的是**它的第一帧**，不是它最好看的那个节点。这条规则是量出来的：第 1 章最早写的两条路线日期是 1763 与 1781，于是从 1607 到 1763 整块版面是空白纸——占这一章一百七十六年的其中一百五十六年，而这恰恰就是这一层本来要修的毛病。补上 1607、1754、1775 三处更早的路线就是答案，验证指标是纸面上最暗的那个像素：补之前 181，补之后 96。

它们对运行时的开销是零，因为 figure 进包的形式是一条 `LineString`，而插图框边框本来就是这种东西。于是日期遮罩、淡入与粒子消散全部继承自已有的机制：没有新的 uniform，没有第二种材质，也不存在"运行时投影与构建时的投影对不齐"的可能。

### 它一个播放器都不需要

面板内容就是 `beatAt(beats, state.date)`——当前时刻生效的那个节点——在帧循环里紧挨着日期戳求值。没有故事时间轴、没有队列、没有播放状态。Play 本来就在推动一个日期，面板只是去读它。于是有三件事是白得的，而不用专门去做：

- **往回 scrub 就是在倒着讲故事**，因为面板是游标的函数，不是某个序列的函数。
- **深链接能带上故事。** `?chapter=wwii&date=1944-06-06` 直接开在诺曼底那张卡上，于是一个时刻成了可以粘进聊天窗的东西。
- **Play 变成了纪录片播放**，而这正是这一层存在的理由。

### 它自己就会放

写好的八章按顺序连起来就是一部纪录片，所以地图集不等你来驱动：打开页面它就开始走，从詹姆斯敦一直放到 1 月 6 日，全长二十三分四十九秒。每章时长是 `TRAVEL_SECONDS + beats × HOLD_SECONDS`，如果它的第一个节点就是本章的开场，再减九秒（那次停留属于开场卡，不是阅读时间，见下文），所以各章在 1:59 到 3:32 之间，取决于有多少话要说。

这就把**章末从终点变成了交接**，而这是这个功能真正付出的代价。帧循环原本在游标走到章末时停止播放；现在它会穿过溶图滚进下一章，`playing` 跨过这次换章继续为真，只有最后一章的末帧才真正停下。在一部已经放完的片子上按 Play，会从头再放一遍——因为停下来的单位是整条片子，不是某一章。

导航也不再暂停了。播放中点某一章，意思变成*去这一章*，就像播放器里的跳转——原先在那里暂停，会让观众去翻一翻章节选择器，不知不觉把片子关掉，然后对着静止的页面纳闷哪里坏了。拖动进度条仍然暂停，因为伸手去拿时间轴就是离开故事；Restart 也仍然暂停，因为它是一次倒带。

只有一个东西会让它停住，而它是地图集早就许下的承诺，不是偏好：

- **`?still`。** 让一个链接可以只指定章节而不开始放映——分享"看第 6 章"不该等于"然后就看着它走掉"。它现在是唯一的请求方式，而这正是重点：静止**是可读的**。一页不动会把这个事实写在自己的 URL 里，所以观众能分清"刻意停住"和"看起来坏掉了"。

带日期的链接原本是第二条，而把它去掉是本功能两次反转中的第一次。那条规则读起来很顺——`?chapter=wwii&date=1944-06-06` 是一张要人看的定格画面，所以它停在落点——但它在最要紧的方向上失败了，因为**页面会改写自己的 URL**。观众到达后一秒之内，地址栏里就有了日期。于是每一次刷新、每一个被恢复的标签页、每一个"刚看完那一页"的书签，在那条规则下都是一张定格：自动播放不知不觉变成了只发生一次的事件，而屏幕上没有一个字说明为什么。一条把常见情形变成例外的规则，不是关于链接的规则。

URL 记录什么也跟着变了。游标被**停住**时——暂停、拖动进度条，或者点某一章到达——它带日期，精确到天，所以一次暂停就是一个可以发给别人的链接。片子跑起来时它只带章节：刷新一张会动的画面，从来就意味着*这一卷重放*；而写下一个游标不到一毫秒就会离开的日期，意味着二十四分钟里每秒四次 `history.replaceState`。Safari 在三十秒内超过一百次就抛错，而这段代码跑在帧循环里——第一次抛出就会把整页带走，而且是在地图集从未打开过的那一个浏览器上。现在整条片子只有八次写入。

第二次反转是动效设置，而它是同一个错误往外挪了一层。`prefers-reduced-motion` 不是把片子停住，而是把它**取消**——在任何"系统关掉了动画效果"的机器上都是如此：为了速度调过的老笔记本、公司镜像、远程桌面，这些情形远比"有前庭功能障碍的人"常见。而地图集在同一台机器上对这个设置本来就有两种读法：`ui.css` 读作*更轻*——章节卡照样印上去，只是从两秒缩到 0.6 秒，故事面板直接出现——而 `shouldAutoplay` 读作*别放*。取消内容不是减少运动，所以这个设置现在只做减少，拿走的是跟随指针的视差：全站唯一一件既纯装饰、又由交互触发的动效，也正是 WCAG 2.3.3 真正在说的那种情形。片子自身的运动——游标推进、边界重绘、章与章之间的溶图——就是要被传达的那个东西，而一个不动的地图集是一个空无一物的地图集。

片子没开始时，dock 会说出来——Play 按钮旁边写着 *Held still by the link*，只在游标不动的时候显示。这个原因在画面里看不见，而把它咽下去的代价，就是上面两次反转共同的样子：一页拒绝移动、又一个字不说，读起来就是坏掉了。

同一个道理也适用于片子**在跑的时候**站着不动——这一层要等到第二次反馈才被看见。一次停留是画面里看不见的：在它持续的那段时间里，图纸、日期戳、时间轴全都合法地静止，和"页面死掉了"是同一帧；而整条片子大约十分之九的时长都花在停留上。所以 dock 把它也画出来：时间轴下面一条细线在停留期间填满，Play 按钮上方一行字把它倒数出来——*Standing on a beat — 8s*。游标行走时两者都是空的，片子暂停时两者也停住不动——这是诚实，不是整齐：钟本来就停了。

### 代价是什么，以及为什么光有 pace 不够

播放*就是*日期游标在移动，所以一章里每隔几秒就有东西要读时，它必须停下来。第一版做法是给这种章节一个更慢的 *pace*——每秒推进本章跨度的百分之几，全章统一——让整章正好等于"每个节点一次停留"。在真实播放里采样之后发现：那不是纪录片。**统一 pace 等于把两个日期之间的间隔当成了阅读时间**，于是珍珠港之后两个月的第 9066 号行政令只在屏幕上待了 6 秒，而一年之后的中途岛却待了 27 秒。这两个数字都不是谁定的，都是历史恰好那样发生的副产品。

所以改成游标在每个节点上**停住**。`holdsFor` 是要停的日期表，`HOLD_SECONDS` 是每次停多久，而 pace 退化成节点*之间*的行走。现在无论两个时刻相隔一个月还是十年，每个节点拿到的阅读时间都一样，变的是行走——这是诚实的，因为行走本来就不需要读。停在节点上时几何也停住，画面是被定格的一镜，不是移动的一镜。

有一个节点的价格低于阅读时间，而它恰恰是最要紧的那一个。一章的**开场**节点不是被发现的，它跟着章节一起来——章节卡正在图纸上盖印，宣告它——所以它按那张卡的在屏时长停留（`OPENING_HOLD_SECONDS`，约三秒），阅读时间留给真正是新闻的那些节点。第一章就是把这条逼出来的那个案例：它的第一个节点就落在本章开场的那一天，于是片子曾经以十二秒静止的、几乎空白的纸面**开场**——第一章按设计本来就没有边界几何，它的开场路线是一条只有图幅百分之一宽的走廊，而章节卡和日期戳都不会变，因为日期没有在走。这十二秒是任何人看这座地图集看到的第一样东西，也正是"它走到 1619 前后就停住"第二次被报上来时的真实含义。让一次到达按它自己宣告的时长停留，同时也让章与章的交接不再读成"八部片子中间插了一段暂停"。

状态机被告知的是一个 pace、一张日期表，以及*两个*时长——阅读时间与到达时长——它从不知道那些日期上有什么。`src/env/chapter.js` 依然对历史一无所知；全部耦合就是 `src/main.js` 里的 `applyStoryTiming`。

### 叙事层现在做不到的事

**一百零八个节点里有十四个不在地图上。** 用真实投影量过而不是估计：九十个落在图纸上，四个落在插图框里——珍珠港与另外两个夏威夷节点在夏威夷框内，阿拉斯加建州在阿拉斯加框内——剩下十四个完全落在纸外。它们是巴拿马运河，以及太平洋与欧洲战场、柏林空运与柏林墙、朝鲜、斯普特尼克、海湾战争、苏联解体，和阿伯塔巴德的那座院落。

这是历史本身如此，不是数据缺陷。图纸是按本土四十八州拟合的，在它的比例尺下太平洋在西边之外，欧洲在东边之外。另一种做法是在版面上随手取一个点，管它叫诺曼底——那是在**说谎**，而且是在最要紧的那个场合悄悄地说。

所以 `pipeline.test.js` 钉住的是这条分界本身，而不是意图。往一个画不出来的地方加节点，现在会被迫正面回答这个问题，而不是悄悄生成一个指向空气的镜头目标。把地点变成镜头运动是 M4 的活儿，那十四个就是它的任务书。

这张表里有两点值得把话说满，因为两点都是承重的：

- **第 1 章没有边界几何，但照样构建。** 触及它窗口的每一个要素都起始于它的结束日，所以只按边界切出来的包会是 176 年的空白纸，然后在最后一帧闪出一张地图。这一章改为由自己节点携带的路线来画——詹姆斯河、大篷车道、宣告线、通往康科德的路、约克镇行军——也正是在这里，叙事层从地图的同伴变成了版面据以绘制的东西。AHCB 确实存有殖民地时期的边界，但从 1629 年起、且是县级；要画它们就得引入第二套大得多的数据集，而县级几何是明确的非目标。从外部看，一个空章节与一个坏掉的章节无法区分，这本来就是当初不建第 1 章的理由——所以管线现在拒绝为一个标记为 `built` 却什么都没画出来的章节写出数据包。
- **第 6、7、8 章是版面，不是历史。** 这不是数据缺口，而是记录本身如此。1912 年之后国土轮廓不再移动，所以这几章无法靠边界变更支撑，必须靠别的东西——三章合计 39 个撰写节点，落在一条边界都不动的窗口上。插图框在这件事上也帮不上忙：两块都出现在第 4 章内部（1867 与 1898），而且从出现那天起就是静止的，它们给第 4 章换来两次视觉事件，给第 5–8 章一次也没有。

### 相对初稿改了什么，为什么

- **纪录片各集的年份区间彼此重叠，还留下了空洞。** 西进（1803–1860s）与分裂（1820s–1860）占用了同一个四十年；腹地（1865–1890s）与城市（1870–1900）占用了同一个二十五年。这在主题式电视叙事里没问题，但一条时间轴上，同一年只能有一个状态。上表按历史转折点重新切分——1783（巴黎条约）、1848（墨西哥割让）、1865、1900、1941、1945、1989——区间不再打架。
- **1783–1803 的空洞已补上。** 原本没有任何一集覆盖这段：邦联时期、《西北法令》（1787）、制宪会议、以及 1803 年的路易斯安那购地。而这些恰恰塑造了此后所有的边界。现在归第 2 章。
- **十二个视觉主题，实际只有七个。** 第 1≡2、4≡5、6≡7、10≡11 集被赋予了完全相同的材质，第 8、9 集同为报纸质感。上表才是诚实的数量。
- **合并策略与主题表自相矛盾。** 它把第 6、7、8 集并为一个连续阶段，可第 8 集的材质（报纸、金色）与第 6、7 集（蓝图、铁锈）并不一致。改为在 1900 年切开即解决。

## 时间轴模型

**章内连续，章间离散。** 这条同时化解了"时间作为第一公民"与分节叙事之间的张力：

- **章是导航单位。** 分节选择器是主要控件——一份章节名列表，如同参考案例底部那份地块名列表，每一章点一下就到。
- **章内时间是连续的。** 日期可以自由拖动；边界按日期从带有效期区间的几何数据实时推导，所以墨水是真正在生长，而不是在若干张存好的画面之间切换。
- **每章自带时间尺度。** 各章不去争夺轴上的固定份额，因此一个四年的章节不会被一个一百六十年的章节压扁。这就是"早期过于拥挤"问题的解法——靠结构解决，而不是靠手调。
- **锚点逐章声明。** 每章一到三个锚点边界状态，加上一组关键事件，数据来自 AHCB 的 `CHANGE` 字段，其中存有每一次边界变更的人类可读说明。

### 数据管线才是真正的活儿

AHCB 发布的全国 shapefile 约 142 MB，内含按日期编码的重叠多边形。这些东西原样进不了浏览器。管线如下：

```
AHCB shapefile
  → 按章节日期范围筛选（在章节结束处取半开区间）
  → 投影，每个区域走自己的投影器
  → 用 Douglas-Peucker 简化（单一容差，由像素预算定）
  → 追加插图框边框与该章撰写的故事路线，不做简化
  → 量化并编码为 TopoJSON
  → 每章一份分发包，按需加载
```

每个要素保留 `START_DATE` / `END_DATE`，因此边界在运行时按日期推导，而不是按日期预先烤好。没有成堆的快照需要分发——参考案例同样是这么做的。边框与路线是在简化**之后**才进包的，因为两者本来就是有人有意画成的形状，而 Douglas-Peucker 只会"通常"同意。

### 动效：用 GSAP，以及为什么不手写

本表初稿写的是*不用动效库*，照参考案例的做法。这条推翻了。参考案例手写缓动，是因为它从不需要编排彼此重叠的序列——它的电影模式只是用单一进度值在六种构图之间切换。**而 M4 恰恰改变了这个前提**：从地图飞入历史现场，是编排式的多轨运动——重叠的时间线、错峰的元素、手调曲线——这正是时间线库存在的意义。从 M0 就采用它，意味着相机导演只写一次，且一开始就用 M4 需要的语汇。

三种用途，彼此分开：

- **编排序列**——章节转场、相机导演、粒子消散——用 `gsap.timeline`。
- **连续状态**——章节权重、日期游标、跟随拖拽的相机——用 `gsap.quickTo`，它每次调用都在重新瞄准移动中的目标，而不是重建 tween。
- **瞬移**——深链接与章节跳转——用 `gsap.set`。

### 投影与插图框

地图采用 **Albers 等积圆锥投影**（EPSG:5070，NAD83 / Conus Albers）。它是美国国家级地图的标准——USGS、人口普查局与《美国国家地图集》都用它——而对我们而言理由很具体：它**等积**，州在纸面上的分量与其真实大小一致。墨卡托保的是角度，这正是方形地图瓦片得以成立、也是它成为网页地图标准的原因；但它的面积误差按 1/cos²(纬度) 增长，在 60°N 已达约 4 倍。用墨卡托画，阿拉斯加看上去会比本土四十八州大出好几倍。对一个主题就是"疆域"的项目来说，这是错的工具。

**阿拉斯加与夏威夷做成插图框**，不属于主图。这是符合时代惯例的做法——历史上的美国地图都这么画——也是投影文献推荐的方案，因为强行用一种投影覆盖整个纬度带，会同时扭曲这三块区域。阿拉斯加用 Alaska Albers（EPSG:3338），夏威夷用自己的一套圆锥投影；排布方式即 `d3-geo` 的 `geoAlbersUsa` 所实现的合成布局。哥伦比亚特区 68 平方英里，在州级简化下就是一个标记加一个标签，不是多边形。

**两块插图框在纸面上占的是固定位置，纸面并不会为了容纳它们而生长。** 每块插图框都只拟合一次——依据整份记录，拟合进一块在任何章节里都是开阔水面的矩形：图纸左下角，墨西哥湾岸以南、得克萨斯以西。实测：这两块矩形与投影后的本土最近的一块陆地之间，净空约 0.012 个图纸单位——按图纸比例约 55 公里；这条净空在 `pipeline.test.js` 里用多边形与矩形的精确相交来断言，而不是靠眼睛看。所以没有什么需要预留，也没有什么需要重新取景：那块空间本来就在。本文档的早期版本说"日期走到 1867 年时纸面生长、相机随之重新取景"。那是错的，而且错得值得记一笔：当时是**先假定插图框需要地方**，谁也没有去量那个角。

**挂在日期上的是插图框里的内容，不是它的位置。** 阿拉斯加最早的几何是 1867-03-30 的购地，夏威夷最早的是 1898-07-07 的吞并。日期游标走到它们之前，插图框不画，那个角就是水。边框与框里第一件东西同一天到位，这也是它挂在数据上、而不是写死的原因——规则是"边框和它框着的最老几何同岁"——而且它此后再不离开，因为边框不是边界。插图框的出现是一次边界事件；插图框**在那里**则是地图绘制本身。

**而这也正合适，因为插图框从不改变形状。** 阿拉斯加的轮廓在它四个带日期的版本里完全相同——1867 年的 Department、1884 年的 District、1912 年的 Territory、1959 年的 State；夏威夷在它自己那三个版本里也完全相同。把每一个包里所有插图几何的投影坐标做哈希，**十五个几何塌缩成恰好两个形状**。AHCB 每次只是把同一个轮廓登记到一个新的政治名称下，范围从未移动。所以插图框贡献的是*出现*，不是运动：那个角本来是水，从 1867 年起它是阿拉斯加；此后框里唯一改变的东西是名字。这比"又多两章的边界内容"要小得多，而且值得把话说满：这正是注解层要作为里程碑、而不是点缀的理由——在插图框里，`CHANGE` 字段和标签**就是**历史，此外没有别的东西可展。

**让它留在本土之外的机制是路由，而不是排除。** 单一 Albers 投影放不下阿拉斯加或夏威夷——不是因为它报错，恰恰因为它不报错：它返回有限坐标，落在本土四十八州所拟合的那张图纸之外，然后照样被画出来。在这一点被处理之前实测：阿拉斯加在图纸左上角留下一道薄片，且每个版本占 6,671 个点，约为那几章载荷的 44%、三角化开销的一半，全都花在不在图上的几何上。

最初的修法是加过滤器：`pipeline/lib/placeable.js` 问"这个该不该被投影？"，不合的就丢掉。这个守卫形状是错的，文件已经删除。过滤器在遇到**本土**要素判断错误时是静默的——要素消失，而地图看起来仍然像地图；而且它只能表达"阿拉斯加不许画"，表达不了"阿拉斯加属于阿拉斯加那套投影"。现在的规则是一张路由表 `pipeline/lib/regions.js`：每个几何按 id 归入某个区域，每个区域有自己的投影与自己的一次拟合。几何不可能"投影失败"，所以失败形态不再是*少了东西*，而是*东西在错的位置*——后者在屏幕上是看得见的。`pipeline.test.js` 把两半都钉住了：`ak_*` 与 `hi_*` 路由到各自的插图框；以及本土投影对阿拉斯加**仍然会返回有限坐标**——这正是当初那个过滤器所要补偿的事实，也是一块被误画的插图框过去看起来还挺像样的原因。

整部地图集的投影是固定的。锚点必须正好压在接替它的那条边界之下；逐章换投影等于刻意破坏这种套准。

### 为什么不用 GitHub Pages

Pages 对站点大小限制 1 GB、单文件限制 100 MB，且不支持 Git LFS。对于一个载荷就是几何数据的项目来说，尺寸不对。用 Vercel——或者继续用 Pages，但把首屏包体限制在单章之内。

### 性能

参考案例选择主动降质而非掉帧：它会在关键时刻采样帧率，指标不够就下调参数，并把选定的画质档位按浏览器记忆下来。我们照做。目标是在核显的中端笔记本上跑满 60 fps，并且每一档画质都必须保持可读。

## 数据来源

- **Newberry Library — Atlas of Historical County Boundaries（AHCB）**，John H. Long 等编，Dr. William M. Scholl 美国历史文化中心。覆盖 **1629-03-04 → 2000-12-31**，精确到日，WGS84；**含全部五十州与哥伦比亚特区，阿拉斯加、夏威夷在内**。全国州与领地合成数据自 1783 年开始；县级数据可回溯至 1629 年。全国数据文件于 2012 年发布，五十州于 2010 年全部完成，项目现已关闭。以下两条的上游都来自它。

- **ropensci/USAboundaries** — 基于同一份 AHCB 数据的 R 包，便于整形与校验推导出的几何。
- **OpenHistoricalMap** — OSM 式的历史地图，同样吸收了 AHCB，值得作为交叉验证来源评估。
- **NHGIS / IPUMS（明尼苏达大学）** — 州与县级边界文件可回溯至 1790 年，1990 年起的全部普查单元齐备，另有可驱动城市光点与聚落密度的入口统计表。免费，但属于**限制性许可**：必须署名，未经许可不得再分发。正因如此，它提供的是统计与交叉验证，而不是我们分发的几何。
- **TIGER/Line（美国人口普查局）** — 现代边界数据的来源，也是我们实际分发的那个。它**不受版权保护**，在产品中使用并致谢普查局即可。NHGIS 从 1990 年起的边界文件本身只是对它的轻度重新包装，因此这是同一份信息，许可更简单。
- **American Panorama**、**Chronicling America** — 交互模式与事件、报纸元数据的参考。

### 覆盖范围的边界，说清楚

- **1629 年之前没有数据。** 第 1 章以 1607 年开场是出于叙事，但边界几何只从 1629 年起存在。1629 年之前只用聚落光点表示，绝不用填色疆域。在打包的州级记录里这个下限还要更晚——**1783-09-03**——这正是第 1 章的包里一个边界多边形都没有、只有自己节点携带的路线的原因：见上文「构建状态」。
- **1912 年之后不再移动。** 从 1912 年 2 月亚利桑那建州到 1959 年 1 月阿拉斯加建州之间没有任何州加入，而那次空白之后的两次加入同样没有移动任何线条——两次都在插图框里，而插图框保持它们早就有的轮廓。因此第 6、7、8 章画的是一张轮廓固定的本土四十八州，外加两块比它们更早就已固定的插图框，它们的内容来自另一层——已经写完的叙事层。这是关于美国历史的事实，不是数据源的缺陷。
- **AHCB 止于 2000 年，但记录没有止。** 第 8 章一直写到当下——字面意义上的"当下"：它的窗口闭合于 **2026-12-31**，一个有人刻意去改的常量，而不是 `new Date()`；因为一个会在午夜移动的窗口会让构建不可复现，也会让每一个深链接失去稳定性。它从 2000 年起的几何来自 **TIGER/Line**，统计来自 **NHGIS**。这两者发布的是**逐次普查的快照**，而不是带有效期的区间，所以第 8 章是在若干固定状态之间插值，而不是连续生长。这是诚实，而非妥协：2000 年后的变化真实但稀疏，几何本身几乎不动。
- **阿拉斯加、夏威夷与哥伦比亚特区不能简单地砍掉。** Mullen 那张图不含它们，而本文档的早期版本沿用了那个范围却没加以审视。AHCB 本身覆盖全部五十州与特区。排除它们在历史叙述上并不中性：阿拉斯加购地（1867）与夏威夷吞并（1898）都落在第 4 章内；第 6 章以珍珠港开场；1942–43 年的阿留申战役是北美本土唯一的战斗；两者都在 1959 年建州，落在第 7 章内；首府自 1800 年起就在特区，而 1846 年亚历山德里亚县归还弗吉尼亚——那是一次真实的边界变更。**要不要出现**与**怎么画**现在都已定：阿拉斯加、夏威夷用插图框，特区用标记。见上文「投影与插图框」。

## 许可

**代码：MIT。** 见 `LICENSE`。

**数据：CC0 1.0，已无歧义。** AHCB 最初以 CC BY-NC-SA 发布，一些二手资料——包括 rOpenSci 的 `USAboundaries` 文档——至今仍这么写。这个标签此后已被两次取代：Newberry 重建后的站点（2025）明确写明 Atlas 数据以 **Creative Commons CC0 1.0 Universal（公共领域奉献）** 发布，「可无需申请许可即使用」。

本文档早期版本留下的那个问题就此关闭。CC0 是公共领域奉献，因此这份数据可以存在于一个代码为 MIT 的仓库里，两个许可互不沾染——不再需要出于谨慎把它们隔开。

我们仍然把边界数据放在自己的目录、配自己的 `NOTICE` 文件，并在产品内署名来源。不是因为条款要求——条款并不要求——而是因为四十年的州议会法案转录工作不该变得匿名，而这样一份结集值得被引用。

**现代数据源不是 CC0，我们按它们实际的条款对待。** AHCB 的开放是例外，不是通例。**TIGER/Line** 不受版权保护，在产品中致谢普查局即可分发，因此第 8 章的几何以它为准。**NHGIS** 免费，但属于限制性许可：必须署名，未经许可不得再分发，改造后的数据还需重命名并附 FGDC 兼容元数据才可分发。所以 NHGIS 只提供统计与交叉验证，绝不提供分发的几何——何况它 1990 年起的边界文件本就是对 TIGER/Line 的轻度重新包装。两套条款与要求的引用格式都记录在 `NOTICE.md`。

**美术与音频素材：待定。** 原创插画与声音由我们自己授权。第三方采样必须是 CC0 或已明确获准，并登记在 `NOTICE` 中。

**参考材料只引用，不打包。** 纪录片是结构参考；其中任何画面、音频或文稿都不进入本仓库。

## 路线图

已改为深度优先。这个项目的产品就是它看上去的样子——观感不对，别的都救不回来。十条并行的待办只会让所有东西都在动，而真正要紧的那一件事始终没被验证。

### M0 — 垂直切片：先把观感做出来 —— **已完成**

选一章，标准是边界变化最剧烈、材质最干净：**第 3 章 分裂（1848–1865）**。

- 只为该章搭数据管线
- 程序化纸纹与雕版边缘着色器
- 章内的连续边界形变
- 一次粒子转场进、一次出
- 一个锚点层——1861 年脱离线，在 1865 年州界之下仍可辨认
- 一个两章的选择器，让转场真的能被感受到

*验收标准：*一条十五秒的录屏，能让人开口问"这是怎么做的"。做不到，就先改着色器，不要再写下一个功能。

### M1 — 主脊 —— **进行中**

全八章。章节选择器、逐章时间尺度、锚点层、转场、相机状态。音频先留桩。

八章全部建好并可导航——包括完全没有边界几何、整章都由自己的叙事路线画出来的第 1 章。插图框已经做进去了：两块都出现在第 4 章内部（1867 与 1898），且各自从出现那天起就是静止的。它们是这份记录最后画出的新形状。各章之间现在会互相交接，所以八章是连着放的一整条片子，而不是要人一件件启动的八个东西；见「它自己就会放」。这一条上剩下的就是声音，那是 M3。它们能买到什么、买不到什么，见「投影与插图框」；各章情况见「构建状态」。

### M2 — 锚点与标注

内容深度——恰恰是参考案例在评审那里得分最低的地方（内容 7.89，创意 8.53）。写作**已经完成**：八章全部带撰写节点，共一百零八个，第 1 章整章就画自它们。剩下的是其他内容类型——来自 AHCB `CHANGE` 字段的边界变更标注、城市光点、事件标记。

值得记下 M2 按原样做出来会是什么：`CHANGE` 字段的标注是「内华达领地自犹他领地取得土地」这类句子——准确、自动抽取、而且**是在讲更多关于地图的话，不是故事**。叙事层必须是**一种新的内容类型**，而不能是那种标注的延伸，因为差别不在题材上，而在来源上：几何是推导出来的，故事得有人写。它还必须被允许**画线**：十四处手绘几何里有十一处根本不是边界——一条河、路、行军、一条运河、一条铁路——而有一整章除此之外什么都没有。

### M3 — 声音

分章环境音，切章时交叉淡入，首次用户操作后启动。参考案例把声音当作一等层，我们也是。

### M4 — 纵深

从地图飞入历史现场的镜头。注意这里量级变了：这不是数据可视化，而是逐场景的三维美术生产——一个殖民小镇、一片内战战场，各自都是独立的内容工程。单独列一条线，不要让它挡住 M1–M3。

### M5 — 发布

带记忆的画质档位、键盘分节导航、覆盖溶图与相机的 `prefers-reduced-motion`、移动端降级、部署。自动播放那条路径已经把这个设置读作*减少*——它拿走的只是跟随指针的视差——其余动效仍然欠着它；见「它自己就会放」。

### 暂不纳入

- **真实三维地形。** 在观感被验证之前，地图是一张画出来的平面，不是地形模型。
- **上线阶段不做县级几何。** 一万七千多个多边形。先做州与领地级。
- **1629 年之前与 2000 年之后。** 这一条约束的是*边界几何*，不是整个地图集：叙事一直写到当下，而 2000 年之后的边界只能靠编，不能靠出处。

## 开发

模块划分、渲染 pass、画质调节器与加载顺序见 [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)，概览如下：

```
src/
  main.js       启动、帧循环、输入、各系统之间的粘合
  core/         渲染 pass、合成、全局一套 uniform、加载器
  env/          分章状态：权重、色板、日期 → 共享 uniform
  world/        纸面、边界、锚点、标注、相机
  fx/           粒子、城市光点、墨水洇染
  timeline/     八个分章及其叙述
  audio/        分章环境音
  ui/           加载器、章节卡、选择器、控件坞、深链接
pipeline/       AHCB shapefile → 分章 TopoJSON 的构建脚本
public/          图标集;直接分发的字体与贴图
data/           生成的各章数据包（不提交）
```

```
npm install
npm run data:build    # 从 AHCB 源数据重新生成各章数据包
npm run dev
npm run build
```
